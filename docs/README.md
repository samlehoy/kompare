## Documentation Rule

When development changes product direction, data contracts, AI/RAG behavior, or user-visible flows, update:

1. [FUTURE_DEVELOPMENT.md](FUTURE_DEVELOPMENT.md)
2. [BRIEF.md](BRIEF.md)
3. [PRD.md](PRD.md) or [UI_SPEC.md](UI_SPEC.md), if contracts or UI behavior changed
4. [DEMO.md](DEMO.md), if the walkthrough changed
5. [AGENTS.md](AGENTS.md), if agent instructions, project structure, or verification commands changed
